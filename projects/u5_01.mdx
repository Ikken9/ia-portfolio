This hands-on lab provided practical experience with the fundamentals of working within the Google Cloud environment.
I learned to navigate the Google Cloud Console, manage cloud projects, and interact with core platform features used
across most Google Cloud services.

I gained experience creating and switching between projects, understanding how resources are organized, and enabling
APIs to activate specific cloud capabilities. I also worked directly with Cloud Identity and Access Management (IAM),
assigning and adjusting roles to control access to resources in a secure and structured way.

Through the lab environment, I learned to operate within temporary, sandboxed projects, exploring the platform without
risk and gaining confidence with real cloud infrastructure. The course built a solid foundation in using the Google
Cloud Console, managing permissions, enabling services, and understanding how cloud resources are structured and
accessed.
